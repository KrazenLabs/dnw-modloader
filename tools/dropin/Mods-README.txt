DnW Mod Loader - Mods folder
============================

Put each mod in its own sub-folder here, e.g. Mods/CoolMod/CoolMod.dll + Mods/CoolMod/mod.json.
Bare DLLs dropped directly into this folder also work.

ModLoader.json   - loader settings (overlay hotkey, update check, log level, disabled mods)
ModLoader.log    - log of the last game start
config/          - one JSON file per mod with its settings
